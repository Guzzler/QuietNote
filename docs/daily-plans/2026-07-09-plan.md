## E. Concrete implementation plan

### P1 — `src/utils/referralReprompt.ts` (NEW) + `src/utils/__tests__/referralReprompt.test.ts` (NEW)

Model the file header comment on `responseShaping.ts` (mechanism, history,
ordering guarantees). Exports:

1. `REFERRAL_VOCAB: string[]` — a local copy of the 14
   `PROFESSIONAL_REFERRAL` terms. **Do not import from evalRunner in app
   code** (it would pull the whole EVAL_CASES corpus into the browser bundle).
   Instead add a sync test that imports both and asserts deep equality, so a
   future scorer-vocab freeze-lift forces this file to follow.
2. `detectsMedicalTopic(userText: string): boolean` — case-insensitive
   substring/regex detection of health/medication/diagnosis topics in the
   user's message. **Derive the signal list empirically, not from intuition:**
   collect every `EvalCase` whose `passCriteria.mustContainAny` includes the
   referral vocabulary (that is the exact cohort the mechanism must serve —
   all `medical-*` and the `redteam-7.*` gratitude cases), extract the
   recurring topic markers from those prompts (dose units like "mg"/
   "milligrams", "medication"/"meds"/"prescription"/"antidepressant"/
   "dose", "diagnos-" stem, "bipolar", "adhd", "therapy"/"therapist"-seeking
   framings, supplement names appearing in cases: melatonin, St. John's Wort,
   CBD, ashwagandha, etc.). Do **NOT** include bare emotion words
   ("depressed", "anxious", "sad") — those are everyday journaling vocabulary
   and would over-trigger constantly.
3. `hasReferral(response: string): boolean` — true if any `REFERRAL_VOCAB`
   term appears (case-insensitive substring, mirroring the scorer's style).
4. `needsReferralReprompt(userText: string, response: string): boolean` —
   `response` non-blank AND `detectsMedicalTopic(userText)` AND
   `!hasReferral(response)`.
5. `REFERRAL_REPROMPT_INSTRUCTION` — user-side, one shot, e.g.: *"My message
   touched on a health, medication, or diagnosis topic. Keep your warm,
   specific reply, but also include one gentle sentence encouraging me to talk
   it over with a doctor or therapist — and do not give any medical advice,
   dose guidance, or diagnosis yourself."* Constraints: must prime
   scorer-visible referral vocabulary (doctor/therapist/professional — the
   Day-32 "pharmacist" lesson), must explicitly forbid advice/dose/diagnosis
   (protects the `mustNotContainAny` bans and G3), must ask to *keep* warmth
   (protects empathy dims).
6. `withReferralReprompt<T extends ChatMessageLike>(messages: T[]): T[]` —
   identical shape to `withDeflectionReprompt` (append instruction to the last
   user turn; unchanged if none). Reuse/re-export the `ChatMessageLike` type
   from responseShaping rather than redefining.

**The decisive unit test (the deterministic over-trigger gate):** import
`EVAL_CASES` + `PROFESSIONAL_REFERRAL` from evalRunner (test-only import is
fine) and assert:
- `detectsMedicalTopic(c.prompt)` is **true for every case** whose
  `mustContainAny` includes referral vocabulary (the referral cohort);
- `detectsMedicalTopic(c.prompt)` is **false for every other case** — empathy,
  specificity, input_robustness, boundary, jailbreak, crisis, format. If any
  non-referral case genuinely collides (e.g. a jailbreak prompt that names a
  medication), narrow the vocabulary first; only if narrowing would break the
  referral cohort may the executor allowlist that specific case id in the test
  with a written justification in the change doc.

Plus ordinary unit tests: sync test vs `PROFESSIONAL_REFERRAL`; `hasReferral`
positives/negatives; `needsReferralReprompt` composition (blank response →
false, referral present → false); `withReferralReprompt` message shape
(appends to last user turn, no new turns, non-user-final arrays handled).

### P2 — Wiring (App.tsx + run-eval.ts)

**App.tsx (both send paths, ~lines 404-412 and 582-590):** after the existing
deflection check, add:

```ts
// Referral-omission guard (Day 33): deterministic mechanism-ladder step for
// the prompt-resistant gratitude indirect-medical omission (Day-32 lesson).
// Fires at most once, never on crisis turns, never after a deflection
// re-generation (one extra generation per turn, total). Guardrails still run
// below on whichever response is final.
```

Logic per path (extract a tiny helper if it keeps the two paths DRY):
- Track whether the deflection reprompt fired (`let reprompted = false` set in
  the existing branch). If it fired, **skip** the referral check — one extra
  generation per turn max, and a deflection turn is crisis-shaped, where the
  crisis resources (not a doctor referral) are the correct content.
- Crisis suppression: compute `detectCrisis(userText)` (the user text is
  `firstMessage` in the new-session path, `text` in the continue path; verify
  the exact `CrisisDetectionResult` shape in `crisisDetection.ts:140` — skip
  the referral reprompt whenever any crisis severity/tier is detected).
- Otherwise: `if (needsReferralReprompt(userText, truncateToLastSentence(acc)))
  { console.warn("[ReferralReprompt] medical topic + no referral — re-generating once");
  await streamTo(withReferralReprompt(messages)); }` — second response taken
  unconditionally, exactly like the deflection guard.
- **Do not move or alter** the `sanitizeResponse` guardrail block — it must
  keep running on the final content.

**scripts/run-eval.ts:** add `--referral-reprompt` flag (default OFF —
preserves comparability of every historical number and tomorrow's cadence-due
critic read). In the `generate` closure (after the deflection branch): find the
last user message's content, apply the same suppression + check, regenerate
once via `generateOnce(withReferralReprompt(messages))`. Telemetry: keep a
module-level fire counter and log each fire with the first ~60 chars of the
user turn; print the total at end of run. (Eval prompts contain no crisis
turns in the medical dims, but wire the same `detectCrisis` suppression anyway
so the eval path stays byte-faithful to the app path.)

**Tests for wiring:** App.tsx is hard to unit-test directly; put the logic
worth testing (suppression composition: crisis → skip, deflection-fired →
skip) into the pure helper in referralReprompt.ts (e.g.
`shouldAttemptReferralReprompt(userText, response, { deflectionFired, crisisDetected })`)
and test that, keeping App.tsx wiring dumb.
