### Key Developments Since Last Assessment

1. **Transformers.js v4 is a major upgrade opportunity:** Released Feb 9, 2026 after 11 months of development. The new WebGPU runtime is completely rewritten in C++, delivering 4x speedup on GPU-accelerated models. Supports Mamba (state-space models), MLA, and MoE architectures. Bundle sizes dropped 53%. Universal hardware acceleration works across browser, Node.js, Bun, and Deno. **QuietNote's Transformers.js backend should be upgraded to v4 to take advantage of these improvements.**

2. **Browser WebGPU coverage is now universal:** Chrome 113+ (shipping since May 2023), Firefox 141 (Windows), Safari 26 (macOS, iOS, iPadOS, visionOS). This removes WebGPU as a barrier to adoption.

3. **LiteRT-LM migration path clarified:** Google officially recommends migrating from `@mediapipe/tasks-genai` to LiteRT-LM for new work. The MediaPipe API remains functional but is on a deprecated path. Gemma 4 E2B runs under 1.5GB RAM via LiteRT-LM on mobile. Migration should be planned but is not urgent — current MediaPipe package works.

4. **MLC web-llm Gemma 4 still blocked:** mlc-llm#3477 remains open. The `gemma4` architecture requires config changes (nested `text_config` fields) and new weight prefixes (`model.language_model.*`). No timeline for resolution. WebLLM is effectively locked to Gemma 2 2B for now.

5. **Chrome Built-in AI maturing:** The Prompt API is available in Chrome 138+ behind feature flags. Uses Gemini Nano (on-device, no download needed on supported browsers). Limited to English text, single-turn tasks. Could be a lightweight 4th backend for Chrome users in the future, but not suitable as a primary backend due to quality and language constraints.

6. **ONNX Runtime Web + WebGPU:** Stable since ONNX Runtime 1.17. Powers Transformers.js under the hood for ONNX model execution. The existing Transformers.js backend already leverages this — no separate ONNX backend needed.
