## E. Model & Runtime Research

### Gemma 4 E2B — Status Update (April 2026)

| Runtime | Gemma 4 E2B Support | Notes |
|---------|-------------------|-------|
| **@mlc-ai/web-llm** | NOT YET | Open issue mlc-llm#3477 — architecture incompatibility |
| **Transformers.js v4** | YES (ONNX Q4) | `onnx-community/gemma-4-E2B-it-ONNX` — already configured in QuietNote |
| **MediaPipe LLM Inference** | YES (.task format) | `litert-community/gemma-4-E2B-it-litert-lm` on HuggingFace — **but has open bug (mediapipe#6270): memory access out of bounds on Chrome 146 / M4 Mac** |
| **Chrome Built-in AI** | NO | Only Gemini Nano, only for extensions (Chrome 138+) |

### Key Research Findings

1. **MediaPipe → LiteRT-LM migration:** Google recommends migrating from `@mediapipe/tasks-genai` to `LiteRT-LM` (github.com/google-ai-edge/LiteRT-LM). This is the successor library. QuietNote should track this migration path.

2. **Gemma 4 E2B for MediaPipe is unstable:** The `.task` file exists but has a reported `RuntimeError: memory access out of bounds` bug (mediapipe#6270). **Recommendation: attempt the upgrade but have Gemma 3 1B as fallback.** If the bug is reproducible, keep Gemma 3 1B as the default MediaPipe model until the fix lands.

3. **Gemma 3n E2B:** Real model (released ~June 2025), available as web `.task` file via `gemma-3n-E2B-it-litert-lm`. Uses selective parameter activation (5B raw / 2B effective). Another candidate for MediaPipe backend — may be more stable than Gemma 4 E2B currently.

4. **Qwen 3.5 (0.8B / 2B):** New small models with thinking/non-thinking modes. Worth evaluating for journaling — could offer better reasoning in thought-record mode. Not yet available in MediaPipe/web-llm but could work via Transformers.js ONNX.

5. **Current MediaPipe model mismatch:** The MediaPipe engine uses Gemma 3 1B but the code comments say "Gemma 4 E2B". The model ref says `gemma-3-1b-mediapipe` but the Privacy Dashboard shows "Gemma 3 1B". This is accurate but should be upgraded.
