# Daily Plan — 2026-05-24

## A. Today's Objective

Fix the two **fundamental, blocking** problems that make QuietNote's core journaling loop unusable: (1) guided modes that vanish the moment the user types their first message, and (2) the 2048-token context window that makes the model forget the start of a 5-step Thought Record before the user finishes it. Until these are fixed, every other feature is window dressing on a broken core.

## B. Why This Matters

Recent weeks have shipped a lot of *peripheral* polish — continuity cards, session reflections, mood-journal correlations, ThoughtRecord history, personality settings. None of that lands if the central interaction is broken. Right now:

- A user selects **Thought Record** → sees "Step 1 of 5: What happened?" → types one sentence → hits send → **the entire guided UI disappears**. They are now staring at a plain chat thread with no idea what step they are on or what comes next. Same for Gratitude (3 steps) and Check-In. The structured modes are *advertised* but *unusable past message #1*.
- In any mode, by message #4 the model has already forgotten message #1 because the conversation history budget is roughly 1336 tokens (~3-4 exchanges). The user notices: the model's responses stop referencing earlier content. It feels like talking to someone with amnesia.

These are the two things a returning user would notice and quit over. Today we fix both — concretely, with code-level specs the execution task can implement in one session.

### Problem 2: Context window is 2048 tokens — CONFIRMED in code

[src/utils/tokenEstimator.ts:13-23](src/utils/tokenEstimator.ts#L13-L23):

```ts
export const MODEL_CONTEXT_LIMIT = 2048;
export const RESERVED_FOR_GENERATION = 512;
export const RESERVED_FOR_SYSTEM = 200;
export const AVAILABLE_FOR_HISTORY =
  MODEL_CONTEXT_LIMIT - RESERVED_FOR_GENERATION - RESERVED_FOR_SYSTEM;
// → 1336 tokens for ALL history
```

Notes:
- The comment block still references **TinyLlama 1.1B** even though all three runtimes ship Gemma (2 2B via WebLLM, Gemma 4 E2B via the other two). Gemma 2 2B supports 8192 tokens natively; Gemma 4 supports more.
- The system prompt has grown a lot since `RESERVED_FOR_SYSTEM = 200` was set — it now includes cross-session context, journaling-mode instructions, personality directives, crisis/guardrail wording. Realistic system prompt is now ~400-600 tokens. The estimator already measures `systemTokens` dynamically in `buildManagedMessages` (good), but the *advertised constant* is stale and the global limit is the real blocker.
- `RESERVED_FOR_GENERATION = 512` is wildly generous for the actual 2-4 sentence responses the model gives. 256 would be more honest.
- The tokenEstimator test at line 184-185 caps `MODEL_CONTEXT_LIMIT` at `<= 8192` — Gemma 2 2B sits exactly at that ceiling, so we have room.

### Priority 3: Multi-turn coherence regression test

**File to create:** **[src/utils/__tests__/tokenEstimator.multiTurn.test.ts](src/utils/__tests__/tokenEstimator.multiTurn.test.ts)**

A scenario test that mirrors real journaling usage:

```ts
import { describe, it, expect } from "vitest";
import { buildManagedMessages } from "../tokenEstimator";

describe("buildManagedMessages — multi-turn journaling scenarios", () => {
  it("retains a full 5-step Thought Record exchange", () => {
    const systemPrompt = "x".repeat(2000); // ~571 tokens — realistic loaded system prompt
    // 5 user turns + 5 assistant turns, each ~150 chars (~43 tokens)
    const history = Array.from({ length: 10 }, (_, i) => ({
      role: i % 2 === 0 ? "user" : "assistant",
      content: `Turn ${i + 1}: ${"reflective sentence ".repeat(7)}`,
    }));
    const currentEntry = "And the alternative thought I want to hold is...";

    const { messages, trimResult } = buildManagedMessages(systemPrompt, currentEntry, history);

    expect(trimResult.trimmed).toBe(false);
    expect(trimResult.keptCount).toBe(10);
    // system + 10 history + 1 current = 12
    expect(messages).toHaveLength(12);
  });

  it("still trims gracefully when conversation truly exceeds budget", () => {
    const systemPrompt = "x".repeat(2000);
    const history = Array.from({ length: 40 }, (_, i) => ({
      role: i % 2 === 0 ? "user" : "assistant",
      content: "y".repeat(800), // ~228 tokens each
    }));
    const { trimResult } = buildManagedMessages(systemPrompt, "next", history);
    expect(trimResult.trimmed).toBe(true);
    expect(trimResult.keptCount).toBeGreaterThanOrEqual(1);
    expect(trimResult.keptCount).toBeLessThan(40);
  });
});
```

**Acceptance criteria:**
- New test file passes after Priority 2's constants land.
- The same test FAILS if `MODEL_CONTEXT_LIMIT` is reverted to 2048 (sanity check that the test is actually exercising the bump).
