Right now every journal session starts cold — the AI has no idea what you wrote yesterday or last week. This makes it feel like talking to a stranger each time, which undermines the core promise of a "journaling companion." A companion remembers. If you wrote about work stress on Monday, the AI should be able to say "last time you mentioned feeling overwhelmed at work — how has that been?" on Wednesday. This is the single biggest gap in making the journaling experience feel genuinely helpful vs. generic.

Streak tracking addresses the other half of the equation: habit formation. Journaling only helps if you do it regularly, and a visible streak counter with gentle encouragement gives users a reason to come back tomorrow.

### Priority 2: Cross-Session Context in System Prompt

**New utility: `src/utils/sessionContext.ts`**
Create a function that builds a brief context summary from recent sessions and mood data:

```
interface SessionContext {
  recentThemes: string[];       // e.g., ["work stress", "relationships", "gratitude"]
  recentEmotions: string[];     // e.g., ["anxious", "grateful"]
  lastSessionSummary: string;   // e.g., "Yesterday you wrote about feeling overwhelmed at work"
  journalDays: number;          // total days with entries
  moodTrend: string | null;     // "improving" | "stable" | "declining"
}

buildSessionContext(sessions: Session[], moods: MoodEntry[]): SessionContext
  - Look at the last 3 sessions (not the current one)
  - Extract themes from user messages using extractThemes()
  - Get the top 3 themes across recent sessions
  - Get the top 2 emotions from recent moods
  - Build a 1-sentence summary of the most recent session's topic
  - Count unique days with journal entries

formatContextForPrompt(ctx: SessionContext): string
  - Returns a 2-4 sentence context block to append to the system prompt
  - Example: "The user has been journaling for 5 days. Recently they've been reflecting on work stress and relationships. Their mood has been improving. In their last session, they wrote about feeling overwhelmed by a project deadline."
  - Returns empty string if no prior sessions exist
```

### Priority 3: Journaling Streak Tracking on Welcome Screen

**New utility: `src/utils/streakTracker.ts`**
```
interface StreakInfo {
  currentStreak: number;     // consecutive days including today (0 if no entry today yet)
  longestStreak: number;     // all-time longest
  totalDays: number;         // total unique days with entries
  journaledToday: boolean;   // whether there's an entry today
}

computeStreak(sessions: Session[]): StreakInfo
  - Group sessions by calendar day (using createdAt)
  - Count consecutive days backwards from today
  - If today has no entry, count from yesterday (currentStreak is the streak they'll extend by journaling today)
  - Track longest streak ever
  - Track total unique days
```

**Modify `src/components/ChatPanel.tsx` (welcome screen section):**
- Import `computeStreak` and call it with `sessions` (already available as prop)
- Add streak display below the greeting, before the suggestion cards:
  - If `currentStreak >= 2`: Show "🔥 {n}-day journaling streak!" with a subtle flame/streak icon
  - If `currentStreak === 1` and `journaledToday`: Show "You've journaled today ✓"
  - If `currentStreak === 0` and `totalDays > 0`: Show "Start a new streak — your last one was {longestStreak} days"
  - If `totalDays === 0`: Don't show anything (new user)
- Keep it visually subtle — a small badge/pill, not a big banner
- Use Tailwind: `text-sm text-amber-600 bg-amber-50 rounded-full px-3 py-1`
