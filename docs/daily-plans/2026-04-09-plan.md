### MediaPipe LLM Inference — Deep Dive

**Research findings (April 2026):**
- `@mediapipe/tasks-genai` supports Gemma 4 E2B on web via WebGPU
- Uses `.task` model file format (e.g. `gemma-4-E2B-it-web.task`), not `.task` as previously expected
- Performance: ~20-25 tok/s on M3 MacBook, ~30 tok/s on RTX 3060
- Gemma 4 E2B is multimodal (text/image/audio) with 2.3B effective / 5.1B total params, 128K context
- MLC Web-LLM does NOT support Gemma 4 yet (open issue, config incompatibility)
- Transformers.js v4 also supports Gemma 4 E2B via ONNX — already configured in QuietNote

**Why MediaPipe is the next backend to add:**

1. **Google's official on-device path for web**: The LLM Inference API is Google AI Edge's primary way to run LLMs locally in browsers
2. **Gemma 4 E2B support confirmed**: Can run the same model generation as Transformers.js but through Google's optimized runtime
3. **Performance advantage**: Google's optimized `.task` format may outperform ONNX Runtime for Google's own models
4. **WebGPU-native**: Designed for WebGPU from the ground up
5. **Web Worker support**: Can run inference in a worker to avoid blocking the UI thread

**Implementation approach:**
- Use `@mediapipe/tasks-genai` package
- Implement the existing `InferenceEngine` interface
- Load Gemma 4 E2B `.task` bundle from Google's model hosting
- Add as third option in the runtime selector
- Keep code-split like the other backends

**Known risks:**
- WebGPU required — no WASM fallback (unlike Transformers.js which supports both)
- Streaming support uses callback pattern, not async iterator — needs wrapper
- Model bundle delivery — `.task` files hosted on Google's CDN
- Browser compatibility — requires Chrome/Chromium with WebGPU support

### Design Doc Reference
The existing design doc at `docs/design/2026-04-02-local-gemma-runtime-plan.md` recommends MediaPipe + Gemma 4 E2B as the primary migration path (Option B). The runtime adapter architecture (Phase 1) is complete. Phase 2 (add MediaPipe backend) is today's primary work.

### Priority 1: MediaPipe LLM Inference Backend

**New file to create:**

1. **`src/inference/mediapipe-engine.ts`**:
   ```typescript
   import type { InferenceEngine, EngineStatus, EngineCapability, LoadProgress, GenerateOptions } from "./types";

   // Use the MediaPipe LLM Inference API for web
   // Model: Gemma 4 E2B in .task format

   export class MediaPipeEngine implements InferenceEngine, EngineCapability {
     readonly name = "MediaPipe";
     private inference: any = null;
     private status: EngineStatus = "idle";

     getStatus(): EngineStatus { return this.status; }

     async checkSupport(): Promise<{ supported: boolean; reason?: string }> {
       // MediaPipe LLM Inference requires Chrome/Chromium with WebGPU or WASM support
       // Check for basic requirements
       if (typeof window === "undefined") {
         return { supported: false, reason: "MediaPipe requires a browser environment." };
       }
       return { supported: true };
     }

     async load(onProgress?: (progress: LoadProgress) => void): Promise<void> {
       this.status = "loading";
       try {
         // Dynamic import of MediaPipe tasks-genai
         const { LlmInference } = await import("@mediapipe/tasks-genai");

         onProgress?.({ progress: 0.1, message: "Initializing MediaPipe LLM Inference..." });

         // Create the LLM Inference task with Gemma 4 E2B
         this.inference = await LlmInference.createFromOptions({
           baseOptions: {
             modelAssetPath: "https://storage.googleapis.com/mediapipe-models/llm_inference/gemma4_e2b/latest/gemma-4-E2B-it-web.task",
           },
           maxTokens: 512,
           topK: 40,
           temperature: 0.8,
           randomSeed: 42,
         });

         onProgress?.({ progress: 1.0, message: "MediaPipe ready" });
         this.status = "ready";
       } catch (err) {
         this.status = "error";
         throw err;
       }
     }

     async *generate(
       messages: { role: string; content: string }[],
       options: GenerateOptions,
     ): AsyncIterable<string> {
       if (!this.inference) throw new Error("Engine not loaded");

       // Build prompt from messages (MediaPipe uses a single prompt string, not chat format)
       const prompt = messages.map(m => {
         if (m.role === "system") return `<start_of_turn>system\n${m.content}<end_of_turn>`;
         if (m.role === "user") return `<start_of_turn>user\n${m.content}<end_of_turn>`;
         return `<start_of_turn>model\n${m.content}<end_of_turn>`;
       }).join("\n") + "\n<start_of_turn>model\n";

       // MediaPipe uses callback-based streaming — wrap in async iterator
       const chunks: string[] = [];
       let resolve: (() => void) | null = null;
       let done = false;

       const resultPromise = this.inference.generateResponse(prompt, (partialResult: string, complete: boolean) => {
         chunks.push(partialResult);
         if (complete) done = true;
         if (resolve) resolve();
       });

       while (!done) {
         if (chunks.length === 0) {
           await new Promise<void>(r => { resolve = r; });
         }
         while (chunks.length > 0) {
           yield chunks.shift()!;
         }
       }

       await resultPromise;
     }

     async resetContext(): Promise<void> {
       // MediaPipe may not have explicit context reset — recreate if needed
     }

     async dispose(): Promise<void> {
       if (this.inference) {
         this.inference.close?.();
         this.inference = null;
       }
       this.status = "disposed";
     }
   }
   ```
