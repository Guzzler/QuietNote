**Step 2: Create network audit utility**

**New file: `src/utils/networkAudit.ts`**
- Export a `NetworkAudit` class with `start()` and `stop()` methods
- `start()` monkey-patches `window.fetch`, `XMLHttpRequest.prototype.open`, `navigator.sendBeacon`, and `WebSocket` constructor
- Records all outbound URLs with timestamps into an internal log
- `stop()` restores originals and returns the log
- Only active when `import.meta.env.DEV` is true (stripped from production builds)
- Export a `useNetworkAudit()` hook that integrates with React lifecycle

**Modify: `src/components/PrivacyDashboard.tsx`**
- In development mode only, add a "Network Audit" section at the bottom of the Privacy Dashboard
- Shows a list of all outbound requests since the audit started
- Color-coded: green = model download (expected), red = unexpected post-load request
- Toggle button: "Start Audit" / "Stop Audit"
- This gives developers a visual way to verify the no-network-after-load claim

**How to verify:**
- `npm run build` succeeds — audit code tree-shaken out of production
- `npm run test` — all existing tests pass
- In dev mode, Privacy Dashboard shows the network audit section
