# Daily Plan — 2026-04-15

## A. Today's Objective

Build a mood history timeline so users can see their emotional patterns over time — the single most impactful missing feature for making mood tracking genuinely useful.

## B. Why This Matters

Users can log moods today, but they can't *see* them. The MoodInsightsCard shows aggregate patterns (top emotions, correlations, day-of-week) but only after 5+ entries — and even then, there's no chronological view. Without a timeline, mood logging feels like shouting into a void. A visible history creates the feedback loop that makes journaling habit-forming: write, track, see patterns, write more.

**Implementation details:**
- Add `searchQuery` state
- Filter `sessions` array before rendering:
  ```ts
  const filtered = sessions.filter(s => {
    const q = searchQuery.toLowerCase();
    if (s.title.toLowerCase().includes(q)) return true;
    // Check first message content in first thread
    const firstMsg = s.threads[0]?.messages?.find(m => m.role === "user");
    if (firstMsg?.content.toLowerCase().includes(q)) return true;
    return false;
  });
  ```
- Render `filtered` instead of `sessions`
