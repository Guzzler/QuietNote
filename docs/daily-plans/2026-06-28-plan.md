## B. Why this matters

- **Measurement honesty / regression safety.** Day-23 and Day-24 *each* strengthened
  the MEDICAL RULE across all 5 prompts, but neither did a full empathy/specificity
  re-read. Day-24 only ran a `--dimensions=empathy,specificity --per-dim=4` slice
  (32/32) — that touches just 4 of ~11–15 cases per dim per mode. The full Day-22
  baseline was **empathy 44/44 (100%), specificity 56/60 (93%)**. We have not
  confirmed those held after *two* prompt edits. A cumulative empathy/specificity
  drift hiding behind a narrow slice is exactly the kind of regression the daily
  loop exists to catch.
- **The ranked move-list is empty — we need a fresh one.** The Day-22 critic
  ([`docs/critic-reports/2026-06-24.md`](../critic-reports/2026-06-24.md) §4)
  ranked: #1 thoughtrecord referral omission (shipped Day-23, PR #69), #2 scorer-echo
  collision (shipped Day-24, PR #70), #3 checkin question-stacking (shipped Day-22).
  All three are done. The only residue is two *low* watch items (§2.2 therapist-voice
  tic, §4.5 boundary over-promise flicker). The roadmap (Tracks A–D) is fully drained.
  **A fresh critic read is the mechanism that generates the next batch of moves** —
  without it the loop has nothing data-grounded to tune toward.
- **Real users.** §2.2 flagged that ~half of freewrite/gratitude openers had drifted
  to a clinical `[detail] + surfaces / resonates deeply with…` frame — companion-voice
  → therapist-voice drift. It *passes* the scorer (grounds in a real detail) so it is
  invisible to pass-rates, but it makes the companion sound like a clinician taking
  notes rather than a friend listening. If the fresh read shows it has grown, fixing
  it is a direct warmth win. If it has receded, we confirm and move to the next
  weakest finding.

### E.3 — Priority 2: the targeted tune (primary candidate spec)

**Only if §E.1's read confirms the §2.2 therapist-voice tic has grown** (e.g. ≥ ~40%
of freewrite/gratitude openers use the clinical-verb frame AND a reviewer judges it
reads clinical, not warm). Otherwise tune whatever the read names as weakest, or ship
no tune and say so (a clean read with no tunable weakness is a valid, honest outcome —
the loop does not force a change).

**File:** `src/prompts/systemPrompts.ts` (`tune:` only — the single source change).

**Candidate edit (opener-diversity beat, NOT a hard ban):** extend the **Empathy
guidance** block (the "Echo a concrete word…" list) in the prompts where the tic
appears (at minimum free-write + gratitude; apply to all 5 for consistency if the
read shows it cross-mode) with one soft-diversity line, e.g.:

> *"Vary how you open — do not lean on clinical observer verbs like 'surfaces',
> 'resonates deeply with', 'connects to', or 'brings up' as a formula. Speak as a
> friend listening, not a clinician taking notes: name the concrete detail plainly
> ('Crying in the bathroom…', 'Three years beside Miguel…') and react to it."*

**Why this shape (and not a hard ban):** the Day-22 §2.2 note is explicit — the model
evaded the 6 *banned* stock stems by rotating to a new frame; a hard ban on these
verbs would just trigger the next rotation. Soft diversity guidance + the existing
concrete-detail examples nudges variety without a brittle substring war. **Do NOT add
these verbs to the scorer's banned-opener list** (that is a freeze-gated scorer change
and re-runs the whack-a-mole at the scorer level).

**Do NOT touch:** the FIRST LINE RULE stems, the MEDICAL RULE (incl. the new
GENERAL-TERMS REFERRAL beat), the UNINTELLIGIBLE INPUT RULE, the SAFETY CARVEOUT,
the crisis-path question requirement, the AI disclaimer, `crisisDetection.ts`,
`responseGuardrails.ts`, `sessionContext.ts`, `evalRunner.ts`, `evalScorer.ts`,
`EVAL_CASES`.
