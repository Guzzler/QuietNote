The continuity directive targets exactly this shape ("never treat a brief follow-up like 'Yeah.' or 'I'm just so tired of everything' as a fresh topic"). So `mt-3`'s before/after is a near-perfect controlled test of the directive. If `mt-3` flips to referencing the family-dinner/mom context, the prompt-only fix worked. If it still says *"where does that exhaustion show up in your body?"* with no callback, prose is provably not enough and the structural fix is justified — but stays **queued**, because EVAL forbids `feat:`.

3. **The data must drive the decision, and "no tune" is a legitimate EVAL output.** Per [[feedback-eval-tune-combined]], each critic day applies a targeted tune from the weakest finding — but yesterday already spent this loop's one surgical prompt edit on the continuity directive. Today the honest move depends entirely on the re-run: if `mt-3` is fixed, the correct output is to **record the win and tune nothing further** (re-tuning a working prompt is the over-fitting trap). If `mt-3` is still broken, the correct output is **not another reflexive prompt edit** — it is to document that the prompt layer is exhausted for this defect and escalate it to a queued `feat:`. Either way, today applies at most a *documentation* decision, not new architecture.
