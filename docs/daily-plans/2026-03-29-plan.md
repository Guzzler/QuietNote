# QuietNote Daily Plan — 2026-03-29

## A. Today's Objective

Replace the technical header subtitle with user-friendly language, make the sessions sidebar collapse on mobile, and make the welcome card's prompt suggestion interactive — three small polish items that compound on yesterday's humanization work.

## B. Why This Matters

Yesterday's 03-28 work humanized the loading screen and added a welcome card — the "front door" now feels warm. But once a user enters the app, small rough edges remain: the header still says "On-device introspective coach (WebLLM)" (technical jargon), the sessions sidebar takes up space on mobile even when empty, and the welcome card tells users to "Try a journal prompt" but doesn't link to the prompt selector. These are low-effort, high-trust improvements that make the product feel coherent and intentional.

## C. Top 3 Priorities for Today

1. **Replace the header subtitle with user-friendly language** — Change "On-device introspective coach (WebLLM)" to something like "Private journaling companion" or "Your thoughts stay here." The current subtitle is developer-facing jargon that undermines the trust the loading screen just established.

2. **Hide the sessions sidebar on mobile when empty** — On mobile (375px), the Sessions panel renders below the chat at 300px width showing just "No saved sessions yet." This wastes vertical space and pushes the footer down. Hide it on mobile when there are no sessions; show it when sessions exist or on larger screens.

3. **Make the welcome card's "Try a journal prompt" text interactive** — The welcome card says "Try a journal prompt to get started, or just start typing" as plain text. Make "journal prompt" a clickable link/button that opens the PromptSelector, giving users a clear entry point.

## F. UX & Design Review

### How the app feels as a product:
The 03-28 work was a significant leap forward. The loading screen now feels like a real product — warm, reassuring, with helpful context. The welcome card gives first-time users orientation. All modals open and close reliably. Input is never lost. The foundation is solid.

But there's a noticeable tone shift between the loading screen ("Your private journaling companion") and the header ("On-device introspective coach (WebLLM)"). The warm, human language established during loading evaporates the moment the main UI appears. This inconsistency makes it feel like two different products were stitched together.

### What a first-time user would think:
1. Loading: "Oh nice, this is private and it's downloading something just for me. Cool." (warm)
2. Main UI: "On-device introspective coach (WebLLM)... what? Is this still the same app?" (confused)
3. Welcome card: "OK, journal prompt... where do I click that?" (minor friction)
4. Mobile: "Why is there an empty 'Sessions' section below everything?" (clutter)

### Biggest UX gap right now:
**Tone inconsistency between loading screen and main app header.** The loading screen speaks human; the header speaks developer. Priority 1 fixes this in one line.
