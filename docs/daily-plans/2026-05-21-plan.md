# Daily Plan — 2026-05-21

## A. Today's Objective

Make cross-session continuity *visible* to users by surfacing a "pick up where you left off" continuity card on the welcome screen, and give users a memory aid via auto-generated session reflections in the session list (Objective 1 + 2).

## B. Why This Matters

PR #37 (2026-05-08) added cross-session context to the system prompt, so the AI now silently knows what the user has been working through. But the user has no idea this is happening — the continuity is invisible. A returning user opens the app and still sees the same blank welcome screen they saw before.

Making continuity visible does two things:
1. **It tells the user "I remember you."** A clickable card that says *"Yesterday you wrote about feeling overwhelmed at work — how are you feeling about that today?"* is the difference between a stranger and a companion.
2. **It removes the cold-start friction.** The hardest part of journaling daily is figuring out what to write. A continuity prompt eliminates that decision.

Session reflections solve a related problem: the session list currently shows raw title text truncation (known UX issue #27). Users can't scan their journaling history meaningfully. A 1-sentence auto-generated reflection ("Reflected on work stress and a difficult conversation with mom") makes the history browsable and rewarding to look back at.

interface ContinuityPrompt {
  headline: string;       // e.g., "Pick up where you left off"
  body: string;           // e.g., "Yesterday you wrote about feeling overwhelmed. How are you feeling about that today?"
  suggestedInput: string; // text to pre-fill into the chat input on click
  kind: "last-session" | "recurring-theme" | "mood-followup";
}

buildContinuityPrompt(sessions: Session[], moods: MoodEntry[], currentSessionId?: string): ContinuityPrompt | null
  - Reuse buildSessionContext(sessions, moods, currentSessionId)
  - If journalDays === 0: return null (new user, no continuity)
  - If lastSessionSummary present AND last session within 7 days:
      kind = "last-session"
      headline = "Pick up where you left off"
      body = `${when}, you wrote about ${shortTopic}. How are you feeling about that today?`
      suggestedInput = `I want to revisit what I wrote about ${shortTopic}. `
  - Else if recentThemes.length >= 2 AND same theme appears across 2+ sessions:
      kind = "recurring-theme"
      headline = "A recurring thread"
      body = `You've been reflecting on ${theme} across recent sessions. Want to go deeper?`
      suggestedInput = `I want to think more about ${theme}. `
  - Else if moodTrend === "declining" OR moodTrend === "improving":
      kind = "mood-followup"
      body = trend-specific
  - Else return null

**New utility: `src/utils/sessionReflection.ts`**
```
generateReflection(session: Session): string
  - Concatenate user messages from all threads
  - If empty, return ""
  - Extract top 1-2 themes via extractThemes()
  - Extract dominant emotion (if any) via emotionExtractor on combined text
  - Compose:
      - If themes only: `Reflected on ${themes.join(" and ")}.`
      - If themes + emotion: `Worked through ${emotion} feelings around ${themes[0]}.`
      - If emotion only: `Sat with ${emotion} feelings.`
      - If neither: take first 10 words of first user message as fallback.

shouldRegenerate(session: Session): boolean
  - true if reflection is missing OR reflectionUpdatedAt < session.updatedAt
```

**Modify `src/storage.ts`:**
- No schema migration needed — `reflection` is optional. Add helper `updateSessionReflection(id, reflection)` that updates only those fields.

- Cheap operation (no model inference) — safe to run synchronously
