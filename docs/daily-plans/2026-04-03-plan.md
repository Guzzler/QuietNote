Fix the core chat UX gaps — auto-scroll, textarea auto-grow, and Layout overflow — so that the journaling experience feels polished for conversations beyond a few exchanges.

## B. Why This Matters

QuietNote's value is the journaling conversation. Right now, messages disappear below the fold with no auto-scroll (#17), the textarea stays fixed-height making longer entries awkward (#21), and `w-[100vw]` in Layout causes a horizontal scrollbar on systems with visible scrollbars (#23). These are the most impactful UX issues that don't require model changes.

## E. Concrete Implementation Plan

### Priority 1: Auto-scroll chat

**File:** `src/components/ChatPanel.tsx`

- Add a `useRef` for the scroll container (the `overflow-auto` div)
- Add a `useEffect` that scrolls to bottom when messages change or typing animation updates
- Use `scrollIntoView({ behavior: 'smooth' })` on a sentinel div at the bottom of messages
- Test: write multiple messages, verify scroll follows the conversation

### Priority 2: Auto-grow textarea

**File:** `src/components/ChatPanel.tsx`

- Add an `onChange` handler that adjusts `textarea.style.height` based on `scrollHeight`
- Keep `max-h-36` as the upper bound so it doesn't take over the screen
- Reset height when message is sent (textarea cleared)
- Test: paste or type a multi-line entry, verify textarea grows; send message, verify it shrinks back
