## F. UX & Design Review

### How the app feels as a product:
The 03-29 uncommitted changes make a noticeable difference — the header now speaks the same language as the loading screen ("Private journaling companion" matches "Your private journaling companion"), the welcome card's "journal prompt" link provides a clear entry point, and mobile is cleaner without the empty sessions sidebar. The tone is much more consistent from loading → main UI → welcome card.

Two small inconsistencies remain:
1. **Footer**: "All inference on-device • Sessions stored locally" is developer language that appears at the bottom of every page. It should match the trust language used elsewhere ("Your data never leaves this device").
2. **Textarea placeholder**: "Write your journal entry…" reads like a form instruction. A warmer prompt like "What's on your mind?" feels more like a conversation.
