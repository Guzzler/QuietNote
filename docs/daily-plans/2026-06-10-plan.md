## A. Today's objective

Strip the Free-Write empty state from a feature dashboard down to one warm writing invitation (greeting + "just start writing" + a single optional continuity element), quiet the mode strip, and move streak copy out of onboarding — Fundamental Problem 4 ("feels like a tech demo, not a journal"), roadmap item A1.

## B. Why this matters

The real-user data ([`docs/field-notes/2026-06-09-real-user-data-plan.md`](../field-notes/2026-06-09-real-user-data-plan.md)) showed "just start writing" drove **36% of real entries** — yet the first thing a new user sees is a stack of five competing widgets (streak pill, continuity card, correlations card, mood-trend card, 3-bullet feature tour) before a small textarea at the bottom. The app shouts when it should whisper. A person opening a journal at 11pm wants a quiet page, not a dashboard selling them features they haven't used yet. This is the first impression, and per the roadmap it is "the last fundamental problem, validated by data, and the user-visible debt."
