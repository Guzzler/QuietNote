## D. Journaling Modes Exploration

### Current State
QuietNote currently supports only **free-form conversational journaling**. The types file (`src/types.ts`) already defines types for CBT (`ThoughtRecord`, `CognitiveDistortion`), DBT (`DBTSkillPractice`), and structured prompts — but none are wired to the UI.

### Proposed Journaling Modes (ordered by value and feasibility)

#### 1. Guided Gratitude Journaling (BUILD NEXT)
- **How it works:** User selects "Gratitude" mode. The AI presents a structured 3-prompt sequence: (1) "What are you grateful for today?" (2) "Why does this matter to you?" (3) "How did it make you feel?" Each response is saved as a structured gratitude entry.
- **Model integration:** Modify the system prompt per mode to shape the AI's follow-up questions around gratitude themes. The model's role shifts from open-ended reflection to guided facilitation.
- **UI:** A mode selector in the input area (dropdown or tabs). When in Gratitude mode, the welcome card changes to show the gratitude prompt sequence. Progress indicator (1/3, 2/3, 3/3).
- **Why first:** Gratitude journaling is the most well-researched evidence-based journaling practice. It's structured enough to differentiate from free-form but simple enough to implement quickly. The existing `journalPrompts.ts` already has 8 gratitude prompts.

#### 2. Morning/Evening Check-in
- **How it works:** Time-aware mode that presents a short structured check-in. Morning: "How are you feeling? What do you want to focus on today? Any concerns?" Evening: "How was your day? What went well? What would you do differently?"
- **Model integration:** System prompt shifts to check-in facilitator. Responses are shorter and more structured.
- **UI:** Auto-suggested based on time of day. 3-step wizard-style input.

#### 3. CBT Thought Records
- **How it works:** Guided 7-column thought record: Situation -> Automatic Thought -> Emotions -> Evidence For -> Evidence Against -> Alternative Thought -> Re-rating. The AI helps identify cognitive distortions.
- **Model integration:** The model processes each step and offers gentle observations. Types already defined in `types.ts`.
- **UI:** Multi-step form with AI assistance at each step.

#### 4. Stream-of-Consciousness with AI Summary
- **How it works:** User writes freely for a set duration. When done, the AI summarizes themes, emotions, and patterns.
- **Model integration:** Single longer generation at the end rather than turn-by-turn.

**Recommendation:** Build Guided Gratitude first. It's the smallest scope, has clear structure, leverages existing prompt data, and provides a template for other modes.
